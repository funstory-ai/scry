# @scry/sdk (preview)

TypeScript client for `scryd` using `@grpc/grpc-js` and stubs generated by `ts-proto` from `proto/scry/v1/workspace.proto`.

## Quick start

```bash
cd clients/typescript
npm ci
npm run build   # codegen + tsc
```

```ts
import { createScryClient, SearchMode } from "@scry/sdk";

const scry = createScryClient({
  endpoint: "http://127.0.0.1:50051",
  token: process.env.SCRY_TOKEN!,
});
const { workspaceId, rootNodeId } = await scry.createWorkspace("demo");
const ws = scry.workspace(workspaceId);
await ws.mkdirp("docs");
await ws.filesApi.put("docs/plan.md", Buffer.from("hello\n"));
const bytes = await ws.filesApi.get("docs/plan.md");
const hits = await ws.search("hello", { mode: SearchMode.SEARCH_MODE_HYBRID });
console.log(workspaceId, rootNodeId, bytes.toString(), hits);
scry.close();
```

64-bit protobuf fields are generated as `bigint` (`forceLong=bigint`).

## Tests

`npm test` runs Vitest e2e: it builds `target/debug/scryd` via Cargo (from the repository root), starts a throwaway server, and exercises put/get/search.

In CI, the `typescript-sdk` workflow job runs the same after the Rust job.
